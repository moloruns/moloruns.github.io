# Indigo Backdrop V1

`indigo-backdrop-v1.png` is an original generated stadium-environment asset,
created for this project's phase-2.1 art proof on 2026-10-07 with the built-in
image-generation tool. It is not extracted from KOF, NBA Jam or another game.
No people, characters, hoops or playable geometry are part of this image.

Source output retained at:
`/Users/mook/.codex/generated_images/01a112ff-3b3c-7792-9a11-35f5d0c18c3a/exec-6fc4dbb2-bccd-45d1-97f4-7dbba32e56d3.png`.
The project copy is unmodified. Runtime scaling aligns the illustrated stadium
band with the original projected floor; live crowd, signage, court, hoops, ball
and player effects remain separate project rendering.

## Generation Prompt

Use case: stylized-concept. Asset type: original layered 2D game stadium
backdrop for an arcade basketball game. Create a wide 16:9 pixel-art indoor
league arena background, illustrated richly with crisp pixel clusters,
restrained detailed shading, strong architectural perspective, jade green
metalwork, burgundy seating and warm pale-gold lighting. This is an environment
asset, NOT a UI mockup. Composition must suit a fixed full-court side-angled game
camera: put roof trusses and decorative vaulted structural arches in the top
12 percent; three horizontal tiered rows of empty spectator seats and subtle
league pennants between 12 and 28 percent; tunnels and railings along the
boundary at 28-33 percent. The lower two thirds should be unobtrusive flat dark
jade space intended to be covered by separately rendered gameplay floor. Focus
the rich painted details in the upper third and the narrow outer edges. No
people, no players, no creatures, no basketball hoops, no basketball, no readable
text, no logos, no watermark. Clearly drawn architecture and seating, not blurry
atmospheric media. Original art with lively late-1990s/early-2010s 2D arcade stage
craftsmanship, not a copy of an existing game's stage. No gradients or bokeh. Do
not paint a court or court markings because those remain separately rendered
in the game.

This is one stadium art proof, not a completed suite of custom animated stage
atlases. Source/rights notes for existing character sheets remain separate in
`../animations/CREDITS.md`.
