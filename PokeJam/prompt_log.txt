## 2. Overall vs style
Neither mode uses BST or stars. Both compare the same nine attribute percentiles,
including type bonuses. Stars only exist for the game. BST only feeds Clutch,
which isn't compared, though it affects other internal calculations.

- Overall compares the numbers directly. It takes the gap in each attribute and
  combines them into one distance.
- Style first subtracts each profile's own average. Then it compares only the
  pattern: what they're best and worst at relative to themselves.

A three-attribute example. The Pokémon has Speed 80, Shooting 60, Rebound 20:

| Player | Speed / Shoot / Reb | Overall distance | Style similarity |
|---|---|---|---|
| B | 75 / 55 / 30 | 12.2 | 0.992 |
| C | 40 / 30 / 5 | 52.2 | 0.999 |
| D | 55 / 52 / 48 | 38.4 | 0.994 |
| E | 60 / 60 / 60 | 44.7 | 0 |

- C has the same pattern at a much lower level, so it's the worst overall match
  and the best style match.
- D shows a weakness of style mode.

**A real example: Mewtwo**, whose attributes average 95:
- Overall: Kawhi, Cade, Scottie Barnes, Cooper Flagg, Anthony Edwards.
- Style: Quickley, LaMelo, Jrue Holiday, Donovan Mitchell, Caldwell-Pope.

**Does overall end up measuring how strong a Pokémon is?** In practice, mostly
yes, but not by design.
