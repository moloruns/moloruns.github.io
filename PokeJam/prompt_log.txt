## 2. Overall vs style

Neither mode uses BST or stars. Both compare the same nine attribute percentiles, including type bonuses. Stars only exist for the game. BST only feeds Clutch, which isn't compared, though it affects the attributes indirectly because they're built from base stats.

- **Overall** compares the numbers directly. It takes the gap in each attribute and combines them into one distance (Euclidean distance), so a player needs similar numbers to match. How high a profile is and how it's shaped both count.
- **Style** first subtracts each profile's own average. Then it compares only the pattern: what they're best and worst at relative to themselves (cosine similarity). How high the numbers are no longer matters. Your "attribute spread" description is right.

A three-attribute example. The Pokemon has Speed 80, Shooting 60, Rebound 20:

| Player | Speed / Shoot / Reb | Overall distance (lower = closer) | Style similarity (1 = same shape) |
|---|---|---|---|
| B | 75 / 55 / 30 | **12.2** (best) | 0.992 |
| C | 40 / 30 / 5 | 52.2 (worst) | **0.999** (best) |
| D | 55 / 52 / 48 | 38.4 | 0.994 |
| E | 60 / 60 / 60 | 44.7 | 0 (no shape at all) |

- **C** has the same pattern at a much lower level, so it's the worst overall match and the best style match.
- **D** shows a weakness of style mode. D is nearly flat, but its slight tilt points the same way, so it scores 0.994. Style looks at which way a profile leans, not how strongly. If that bothers you, comparing distances after subtracting the averages would keep the size of the spikes.
