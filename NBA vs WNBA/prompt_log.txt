2. Understand what an API does
An API lets your Python code ask a service for data.

A typical request contains:

Endpoint: The URL for a particular kind of data, such as player statistics.
Parameters: Filters such as season, league, or season type.
Authentication: Often an API key identifying your account.
Response: Usually JSON, which Python can turn into dictionaries and lists.
For example, an API might let you ask:

“Give me regular-season WNBA player statistics for this season.”

The exact URL, parameter names, and authentication method depend on the API.

Here is the basic pattern—not a working request until you replace the placeholders with values from its documentation:

import os

}

# Some APIs use a different header or authentication method.

    "Authorization": f"Bearer {os.environ['SPORTS_API_KEY']}"
}

    url,

5. Build a simple similarity model
You don’t need a neural network. Start with standardized features and nearest-neighbor distance.

Within-league standardization asks:

“How far above or below their league’s average is this player on each statistic?”

That makes the results league-relative comparisons, not predictions of how a player would perform in the other league.

Here’s a small example assuming you’ve already created the feature columns:

import pandas as pd
from sklearn.metrics.pairwise import euclidean_distances
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("player_features.csv")

features = [
    "pts_per36",
    "ast_per36",
    "reb_per36",
    "stl_per36",
    "blk_per36",
    "tov_per36",
    "ts_pct",
    "three_point_attempt_rate",
    "free_throw_attempt_rate",
]

# Illustrative cutoff; test how changing it affects results.
df = df[df["minutes"] >= 300].copy()

# Simple prototype policy. Investigate missing data before dropping rows.
df = df.dropna(subset=features).reset_index(drop=True)

# Each league-season gets its own average and standard deviation.
scaled = pd.DataFrame(index=df.index, columns=features, dtype=float)

for _, group in df.groupby(["league", "season"]):
    scaled.loc[group.index, features] = StandardScaler().fit_transform(
        group[features]
    )

def find_comps(player_id, league, season, n=5):
    matches = df.index[
        (df["player_id"] == player_id)
        & (df["league"] == league)
        & (df["season"] == season)
    ]

    if len(matches) != 1:
        raise ValueError("Expected exactly one player-season record.")

    source_index = matches[0]

    # This prototype assumes the table contains just NBA and WNBA data.
    candidates = df[
        (df["league"] != league)
        & (df["season"] == season)
    ].copy()

    if candidates.empty:
        return candidates

    distances = euclidean_distances(
        scaled.loc[[source_index]],
        scaled.loc[candidates.index],
    )[0]

    candidates["distance"] = distances

    return candidates.nsmallest(n, "distance")[
        ["player_name", "league", "season", "distance"]
    ]
A smaller distance means a closer match. It is not a probability or a validated “similarity percentage.”

This baseline weights all features equally. Later, you can adjust weights, account for small samples, and reduce redundancy between correlated statistics.

4. Use league-relative and position-relative normalization carefully
Your position-relative idea makes sense, but I’d avoid relying on exact listed positions alone.

Start with broad role groups
Use something like:

Guards.
Wings.
Bigs.
You can manually curate these for an initial prototype. That is often better than pretending that inconsistent labels such as G-F are precise basketball roles.

Later, you can infer roles from usage, assist rate, rebounding, and shot selection.

Preserve both league and position context
For a statistic (x), calculate:

[
z_{\text{league}} =
\frac{x-\mu_{\text{league, season}}}
{\sigma_{\text{league, season}}}
]

And:

[
z_{\text{role}} =
\frac{x-\mu_{\text{league, season, role}}}
{\sigma_{\text{league, season, role}}}
]

Then, as an initial experiment:

[
x_{\text{adjusted}} =
0.5z_{\text{league}} + 0.5z_{\text{role}}
]

Why keep both?

A center who is an excellent passer for a center should stand out. But that doesn’t necessarily mean they have a point guard’s overall playmaking profile. League context helps preserve that distinction.

With the WNBA’s smaller player pool, narrow positional groups can produce unstable comparisons. Use broad groups, minimum sample requirements, and eventually shrink role-specific estimates toward league-wide estimates.

Counting stats still need an explicit interpretation
You can absolutely use league-relative per-game statistics. Just understand that they include playing opportunity:

A bench player can have a similar style to a starter but much lower per-game production.
Position normalization does not remove differences in minutes.
A good design is:

Role/style features: Rates, percentages, and shot shares.
Production features: League-relative per-game numbers.
Optional opportunity feature: Minutes per game.
That preserves production without letting minutes dominate every part of the comparison.

5. Make feature importance depend on role
For example:

Feature	Guards	Wings	Bigs
Playmaking	High	Medium	Medium
Three-point tendency	High	High	Medium
Rim protection events	Low	Medium	High
Offensive rebounding	Low	Medium	High
But don’t set unusual skills to zero. A great passing big or rebounding guard is exactly the kind of distinctive profile you want to recognize.

For each component, calculate a weighted distance:

[
D_b(p,q)=
\frac{\sum_j w_j(p,q)(x_{pj}-x_{qj})^2}
{\sum_j w_j(p,q)}
]

Then combine components:

[
D(p,q)=\sqrt{\sum_b \alpha_b D_b(p,q)}
]

Here:

(w_j) controls individual feature importance.
(\alpha_b) controls component importance.
Smaller distance means greater similarity.
If weights depend on position, averaging the two players’ role weights makes the comparison symmetric. Otherwise, “A compared with B” may differ from “B compared with A.”

Yes—with one important distinction: regression can help construct the player profiles, but finding the closest counterpart is a similarity-search step.

Ordinary regression needs an outcome to predict. You don’t currently have a training dataset of verified NBA–WNBA counterparts, so you can’t directly train a regression to predict “this player’s correct counterpart.”

Instead, a sensible first version is:

Use regression to estimate a player’s expected statistics given their league, role, and playing time. Then compare how players differ from those expectations.

This is called a regression-adjusted or residual-based similarity model.

1. What the regression would do
For each statistic, fit a model like:

[ \text{Points per game}
\beta_0
+
\beta_1(\text{Minutes per game})
+
\beta_2(\text{Wing})
+
\beta_3(\text{Big})
+
\epsilon
]

Guards are the reference role in this example.

Fit this separately for each league. The model asks:

“How many points would we expect from someone playing these minutes in this role in this league?”

The residual is:

[
\text{Residual} = \text{Actual statistic} - \text{Predicted statistic}
]

Repeat for assists, rebounds, shooting tendencies, and efficiency.

A hypothetical comparison:

Feature	WNBA player	NBA player
Scoring above expectation	High	High
Playmaking above expectation	High	High
Rebounding above expectation	Low	Low
Three-point tendency above expectation	High	High
Those players could be strong counterparts even if their raw averages differ.

Don’t use residuals alone
A league-average guard and a league-average center could both have residuals near zero, despite playing very differently.

For your first version, I recommend blending:

50% league-relative statistical profile
50% regression-adjusted profile
That preserves actual production and tendencies while incorporating position and playing-time context.

The 50/50 split is a starting assumption to evaluate—not something regression discovers for you.

import numpy as np
import pandas as pd

from sklearn.linear_model import Ridge
from sklearn.preprocessing import StandardScaler


PRODUCTION = ["PTS", "AST", "REB", "STL", "BLK", "TOV"]
SHOT_SELECTION = ["THREE_RATE", "FT_RATE"]
EFFICIENCY = ["TS_PCT"]

FEATURES = PRODUCTION + SHOT_SELECTION + EFFICIENCY


def build_profiles(raw):
    df = raw.copy()

    # Example eligibility rules, not universal thresholds.
    # GP * MIN estimates total minutes from per-game data.
    df = df[
        (df["GP"] >= 10)
        & (df["MIN"] >= 10)
        & (df["GP"] * df["MIN"] >= 200)
    ].copy()

    df["THREE_RATE"] = df["FG3A"] / df["FGA"]
    df["FT_RATE"] = df["FTA"] / df["FGA"]

    ts_denominator = 2 * (df["FGA"] + 0.44 * df["FTA"])
    df["TS_PCT"] = df["PTS"] / ts_denominator

    df = df.replace([np.inf, -np.inf], np.nan)
    df = df.dropna(
        subset=FEATURES + ["MIN", "role", "league", "season"]
    ).reset_index(drop=True)

    if set(df["league"]) != {"NBA", "WNBA"}:
        raise ValueError("Expected eligible players from both leagues.")

    if not df["role"].isin(["Guard", "Wing", "Big"]).all():
        raise ValueError("Roles must be Guard, Wing, or Big.")

    if (df.groupby("league")["season"].nunique() != 1).any():
        raise ValueError("This prototype expects one season per league.")

    profiles = pd.DataFrame(
        index=df.index,
        columns=FEATURES,
        dtype=float,
    )

    models = {}

    # Separate fitting prevents the larger NBA sample from dominating.
    for league, group in df.groupby("league"):
        if len(group) < 10:
            raise ValueError(f"Too few eligible players in {league}.")

        # Regression predictors: broad role and playing time.
        X = pd.get_dummies(group["role"], dtype=float)
        X["MIN"] = StandardScaler().fit_transform(
            group[["MIN"]]
        ).ravel()

        # First profile: league-relative feature values.
        Y = StandardScaler().fit_transform(group[FEATURES])

        # Ridge fits a separate linear prediction for each feature.
        # Regularization stabilizes the coefficients.
        model = Ridge(alpha=10.0)
        model.fit(X, Y)

        residuals = Y - model.predict(X)

        # Put residual features onto comparable scales.
        residual_profile = StandardScaler().fit_transform(residuals)

        # Blend production context with regression adjustment.
        profiles.loc[group.index, FEATURES] = (
            0.5 * Y + 0.5 * residual_profile
        )

        models[league] = model

    return df, profiles, models
Why Ridge regression? It is ordinary linear regression with a penalty that discourages overly large coefficients. That is useful with a smaller WNBA sample and correlated predictors.

Here, regression is estimating baselines—not establishing that minutes or position cause a statistic.

5. Find counterparts using role-sensitive weights
Now compare the profiles using weighted Euclidean distance.

We’ll give each component its own weight so that six production features don’t automatically overpower two shot-selection features.

Add this to the same file:

def feature_weights(role):
    # Relative importance inside the production component.
    production = pd.Series(1.0, index=PRODUCTION)

    if role == "Guard":
        production["AST"] = 1.5
        production["BLK"] = 0.5

    elif role == "Wing":
        production["PTS"] = 1.25

    elif role == "Big":
        production["REB"] = 1.5
        production["BLK"] = 1.5

    weights = pd.Series(0.0, index=FEATURES)

    weights.loc[PRODUCTION] = (
        0.50 * production / production.sum()
    )
    weights.loc[SHOT_SELECTION] = 0.30 / len(SHOT_SELECTION)
    weights.loc[EFFICIENCY] = 0.20 / len(EFFICIENCY)

    return weights


def find_counterparts(
    df,
    profiles,
    player_id,
    league,
    n=5,
    same_role=False,
):
    matches = df.index[
        (df["PLAYER_ID"] == player_id)
        & (df["league"] == league)
    ]

    if len(matches) != 1:
        raise ValueError("Expected exactly one eligible source player.")

    source_idx = matches[0]
    source = df.loc[source_idx]

    candidates = df[df["league"] != league].copy()

    if same_role:
        candidates = candidates[
            candidates["role"] == source["role"]
        ].copy()

    source_weights = feature_weights(source["role"])
    distances = []

    for candidate_idx, candidate in candidates.iterrows():
        # Average role weights so pairwise distance is symmetric.
        weights = (
            source_weights + feature_weights(candidate["role"])
        ) / 2

        difference = (
            profiles.loc[source_idx, FEATURES]
            - profiles.loc[candidate_idx, FEATURES]
        )

        distance = np.sqrt(
            (weights * difference.pow(2)).sum()
        )
        distances.append(distance)

    candidates["distance"] = distances

    return candidates.nsmallest(n, "distance")[
        ["PLAYER_ID", "PLAYER_NAME", "league", "role", "distance"]
    ]

6. How to evaluate whether this works
The regression’s prediction accuracy is not the same as the quality of your player comparisons.

For this prototype, test:

Face validity: Do the matches share recognizable roles and tendencies?
Sensitivity: Do matches change dramatically when you move the blend from 50/50 to 60/40?
Sample stability: Are low-minute players producing strange results?
Component explanations: Is a match driven by shooting, production, or efficiency?
Role restrictions: Are unrestricted matches more useful than same_role=True?
Later, collect human judgments such as:

“For this WNBA player, NBA player A is a better comparison than NBA player B.”

Those judgments would let you learn the similarity weights instead of choosing them manually.

For now, this gives you an interpretable first version: regression establishes context, standardized profiles describe players, and weighted distance finds their counterparts.

That gives you one player-season per player from each league to test the model.

The statistics are straightforward to download. Positions need a little more work, because the league-wide statistics endpoint doesn’t provide them. We’ll get positions from team rosters and convert them into the Guard, Wing, and Big roles your model expects.

1. Install the packages

player-comps/

2. Create make_player_seasons.py
Paste the following into that file:

from pathlib import Path
import time

import pandas as pd
from nba_api.stats.endpoints import (
    commonteamroster,
    leaguedashplayerstats,
)


DATA_DIR = Path("data")
CACHE_DIR = DATA_DIR / "raw"

CACHE_DIR.mkdir(parents=True, exist_ok=True)

SEASONS = {
    "NBA": {
        "league_id": "00",
        "season": "2024-25",
    },
    "WNBA": {
        "league_id": "10",
        "season": "2025",
    },
}

STAT_COLUMNS = [
    "PLAYER_ID",
    "PLAYER_NAME",
    "GP",
    "MIN",
    "PTS",
    "AST",
    "REB",
    "STL",
    "BLK",
    "TOV",
    "FGA",
    "FTA",
    "FG3A",
]

# These are starting assumptions, not definitive basketball roles.
ROLE_MAP = {
    "G": "Guard",
    "PG": "Guard",
    "SG": "Guard",
    "F": "Wing",
    "SF": "Wing",
    "PF": "Big",
    "C": "Big",
    "G-F": "Wing",
    "F-G": "Wing",
    "F-C": "Big",
    "C-F": "Big",
}


def get_season_stats(league, league_id, season):
    """Download per-game regular-season statistics, or use cached data."""
    path = CACHE_DIR / f"{league}_{season}_base.csv"

    if path.exists():
        print(f"Using cached statistics: {path}")
        return pd.read_csv(path)

    print(f"Downloading {league} {season} statistics...")
    time.sleep(3)

    response = leaguedashplayerstats.LeagueDashPlayerStats(
        league_id_nullable=league_id,
        season=season,
        season_type_all_star="Regular Season",
        per_mode_detailed="PerGame",
        measure_type_detailed_defense="Base",
        timeout=60,
    )

    stats = response.get_data_frames()[0]

    if stats.empty:
        raise RuntimeError(
            f"No statistics returned for {league} {season}."
        )

    missing = set(STAT_COLUMNS + ["TEAM_ID"]) - set(stats.columns)
    if missing:
        raise RuntimeError(f"Missing expected columns: {missing}")

    stats.to_csv(path, index=False)
    return stats


def get_positions(stats, league, league_id, season):
    """Collect player positions from the season's team rosters."""
    roster_tables = []
    consecutive_failures = 0

    team_ids = sorted(
        int(team_id)
        for team_id in stats["TEAM_ID"].dropna().unique()
        if int(team_id) > 0
    )

    for team_id in team_ids:
        path = CACHE_DIR / f"{league}_{season}_roster_{team_id}.csv"

        if path.exists():
            roster = pd.read_csv(path)
        else:
            print(f"Downloading {league} roster: {team_id}")
            time.sleep(3)

            try:
                response = commonteamroster.CommonTeamRoster(
                    team_id=team_id,
                    season=season,
                    league_id_nullable=league_id,
                    timeout=60,
                )

                roster = response.get_data_frames()[0]

                if roster.empty:
                    raise RuntimeError("Empty roster returned.")

                if not {"PLAYER_ID", "POSITION"}.issubset(roster.columns):
                    raise RuntimeError("Roster is missing position columns.")

                roster.to_csv(path, index=False)
                consecutive_failures = 0

            except Exception as exc:
                print(f"Could not retrieve roster {team_id}: {exc}")
                consecutive_failures += 1

                # Avoid repeatedly hitting an inaccessible endpoint.
                if consecutive_failures >= 2:
                    print(
                        "Stopping roster requests for this league. "
                        "Unresolved roles can be filled manually."
                    )
                    break

                continue

        roster_tables.append(roster[["PLAYER_ID", "POSITION"]])

    if not roster_tables:
        return pd.DataFrame(columns=["PLAYER_ID", "POSITION"])

    positions = pd.concat(roster_tables, ignore_index=True)

    # A traded player may appear on more than one roster.
    # Use the most frequently observed label, ignoring blank labels.
    positions["POSITION"] = (
        positions["POSITION"]
        .astype("string")
        .str.strip()
        .str.upper()
    )
    positions = positions.dropna(subset=["POSITION"])
    positions = positions[positions["POSITION"] != ""]

    positions = (
        positions.groupby("PLAYER_ID")["POSITION"]
        .agg(lambda values: values.mode().iloc[0])
        .reset_index()
    )

    return positions


def build_league_table(league, settings):
    season = settings["season"]
    league_id = settings["league_id"]

    stats = get_season_stats(league, league_id, season)

    # The model requires one row per player-season.
    # Don't silently discard duplicates or average team-stint rows.
    if stats["PLAYER_ID"].duplicated().any():
        raise RuntimeError(
            f"{league} statistics contain duplicate player IDs. "
            "Inspect the cached data before continuing."
        )

    positions = get_positions(
        stats,
        league,
        league_id,
        season,
    )

    table = stats[STAT_COLUMNS].copy()

    table = table.merge(
        positions,
        on="PLAYER_ID",
        how="left",
        validate="one_to_one",
    )

    table["league"] = league
    table["season"] = season
    table["role"] = table["POSITION"].map(ROLE_MAP)

    return table


def main():
    league_tables = [
        build_league_table(league, settings)
        for league, settings in SEASONS.items()
    ]

    players = pd.concat(league_tables, ignore_index=True)

    # Optional manual role corrections.
    overrides_path = DATA_DIR / "role_overrides.csv"

    if overrides_path.exists():
        overrides = pd.read_csv(overrides_path)

        required = {"league", "PLAYER_ID", "role"}
        if not required.issubset(overrides.columns):
            raise ValueError(
                "role_overrides.csv needs league, PLAYER_ID, and role."
            )

        if overrides.duplicated(["league", "PLAYER_ID"]).any():
            raise ValueError("Duplicate players in role_overrides.csv.")

        if not overrides["role"].isin(["Guard", "Wing", "Big"]).all():
            raise ValueError("Override roles must be Guard, Wing, or Big.")

        overrides = overrides.rename(columns={"role": "role_override"})

        players = players.merge(
            overrides[["league", "PLAYER_ID", "role_override"]],
            on=["league", "PLAYER_ID"],
            how="left",
            validate="one_to_one",
        )

        players["role"] = players["role_override"].combine_first(
            players["role"]
        )
        players = players.drop(columns="role_override")

    column_order = [
        "PLAYER_ID",
        "PLAYER_NAME",
        "league",
        "season",
        "role",
        "POSITION",
        *STAT_COLUMNS[2:],
    ]

    players = players[column_order]

    output_path = DATA_DIR / "player_seasons.csv"
    players.to_csv(output_path, index=False)

    # Keep a separate list of records needing manual role assignments.
    missing_roles = players[players["role"].isna()]
    missing_roles.to_csv(
        DATA_DIR / "players_missing_roles.csv",
        index=False,
    )

    print(f"\nSaved {len(players)} player-seasons to {output_path}")

    print("\nPlayers by league:")
    print(players.groupby("league").size())

    print("\nAssigned roles:")
    print(pd.crosstab(players["league"], players["role"]))

    if not missing_roles.empty:
        print(
            f"\nWARNING: {len(missing_roles)} players have no role. "
            "See data/players_missing_roles.csv."
        )

    print("\nPreview:")
    print(players.head().to_string(index=False))


if __name__ == "__main__":
    main()
3. Run the script
From your project folder:

python make_player_seasons.py
The first run may take several minutes because it requests team rosters in addition to statistics. Later runs reuse the cached CSVs.

Your output will have these columns:

PLAYER_ID,PLAYER_NAME,league,season,role,POSITION,GP,MIN,PTS,
AST,REB,STL,BLK,TOV,FGA,FTA,FG3A
POSITION is an extra column for reviewing the role assignments. It won’t interfere with your existing similarity code.

All the counting statistics and MIN are per-game averages. GP is games played. That matches the input expected by build_profiles().

4. Review the role assignments
The weakest part of this automated process is the position-to-role mapping.

For example:

A listed F might actually function as a big.
A G-F might primarily be a guard.
Historical rosters might not contain every player who appeared that season.
Traded players can have inconsistent position labels.
To correct a role without editing downloaded data, create:

data/role_overrides.csv
Its format is:

league,PLAYER_ID,role
Add rows using the actual IDs from your generated file, with a role of Guard, Wing, or Big. Then rerun the script.

Fill missing roles for eligible players before running the model. Your previous build_profiles() implementation drops rows with missing roles, which could otherwise exclude players without you realizing it.

NBA Stats can block or time out on requests, especially from hosted notebooks, cloud servers, or VPN connections. Try running locally first.

from pathlib import Path

import pandas as pd
import streamlit as st

from similarity import build_profiles, find_counterparts


st.set_page_config(
    page_title="Cross-League Player Comps",
    page_icon="🏀",
    layout="centered",
)

DATA_PATH = Path(__file__).resolve().parent / "data" / "player_seasons.csv"


@st.cache_data(show_spinner="Preparing player profiles...")
def load_profiles(csv_path, file_version):
    """
    Cache the prepared profiles so searching does not refit the model.

    file_version is the file's modification timestamp. Updating the CSV
    changes the cache key and causes the profiles to be rebuilt.
    """
    raw = pd.read_csv(csv_path)
    players, profiles, _ = build_profiles(raw)
    return players, profiles


st.title("🏀 Cross-League Player Comps")
st.write("Find an NBA or WNBA player’s closest counterpart in the other league.")

if not DATA_PATH.exists():
    st.error(
        "Player data was not found. Run make_player_seasons.py first."
    )
    st.stop()

players, profiles = load_profiles(
    str(DATA_PATH),
    DATA_PATH.stat().st_mtime_ns,
)

# Alphabetize the search options without changing profile-row alignment.
search_options = players.sort_values(
    ["PLAYER_NAME", "league", "season"]
).index.tolist()


def player_label(index):
    player = players.loc[index]
    return (
        f"{player['PLAYER_NAME']} "
        f"— {player['league']} ({player['season']})"
    )


selected_index = st.selectbox(
    "Search for a player",
    options=search_options,
    format_func=player_label,
    index=None,
    placeholder="Type a player’s name...",
)

if selected_index is None:
    st.caption(
        "Choose a player to see their closest cross-league comparisons. "
        "Only players who meet the model’s eligibility requirements appear."
    )
    st.stop()

selected = players.loc[selected_index]

with st.expander("Comparison settings"):
    number_of_results = st.slider(
        "Number of comparisons",
        min_value=1,
        max_value=10,
        value=5,
    )

    same_role = st.checkbox(
        "Only compare players in the same role",
        value=False,
        help="Restrict matches to the same Guard, Wing, or Big classification.",
    )

results = find_counterparts(
    df=players,
    profiles=profiles,
    player_id=selected["PLAYER_ID"],
    league=selected["league"],
    n=number_of_results,
    same_role=same_role,
)

other_league = "NBA" if selected["league"] == "WNBA" else "WNBA"

st.divider()

st.subheader(selected["PLAYER_NAME"])
st.caption(
    f"{selected['league']} · {selected['season']} · {selected['role']}"
)

col1, col2, col3 = st.columns(3)

col1.metric("Points per game", f"{selected['PTS']:.1f}")
col2.metric("Rebounds per game", f"{selected['REB']:.1f}")
col3.metric("Assists per game", f"{selected['AST']:.1f}")

st.subheader(f"Closest {other_league} comparisons")

if results.empty:
    st.info(
        "No eligible comparisons were found. "
        "Try turning off the same-role restriction."
    )
else:
    display = results[
        ["PLAYER_NAME", "role", "distance"]
    ].copy()

    display.insert(0, "Rank", range(1, len(display) + 1))

    display = display.rename(
        columns={
            "PLAYER_NAME": "Player",
            "role": "Role",
            "distance": "Distance",
        }
    )

    st.dataframe(
        display,
        hide_index=True,
        use_container_width=True,
        column_config={
            "Distance": st.column_config.NumberColumn(
                "Distance",
                format="%.3f",
                help="Lower values indicate a closer statistical match.",
            )
        },
    )

    st.caption(
        "Lower distance means a closer match—not a better player. "
        "Comparisons combine league-relative production, "
        "regression-adjusted profiles, shot selection, and efficiency."
    )

Select their player-season.
Their top five counterparts appear automatically.

The same search includes both leagues:

Select a WNBA player → get NBA comparisons.
Select an NBA player → get WNBA comparisons.
The search only includes players retained by build_profiles(). If someone is missing, check their minutes, games played, missing statistics, and role assignment in the CSV.

This gives you the search-first experience now, while leaving room to add player photos, comparison charts, and “why this match?” explanations later.
